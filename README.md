# حساب معصرة الرضوان — تطبيق أندرويد

1. ارفع محتويات هذا المجلد كما هي إلى مستودع GitHub جديد (الفرع main).
2. افتح تبويب **Actions** ← سيبدأ البناء تلقائياً (أو شغّل Build Android APK يدوياً).
3. بعد انتهائه (~5 دقائق) افتح التشغيلة ونزّل **radwan-olive-press-apk** من قسم Artifacts، ثم ثبّت ملف `app-debug.apk` على الهاتف.

لتعديل البرنامج: غيّر الملف `www/index.html` وارفعه، فيُبنى APK جديد تلقائياً.
الأيقونة وشاشة البداية تُولَّد من الملفات في مجلد `assets`.
