# حساب المنشرة — تطبيق أندرويد

نسخة أندرويد من برنامج **حساب المنشرة** (AL-BENAA CO. · NATURAL STONE).
التطبيق يعرض صفحة البرنامج الأصلية داخل WebView، فكل ميزات البرنامج كما هي.
الأيقونة مأخوذة من شعار الشركة (سقف ذهبي على خلفية خضراء داكنة) وتدعم أيقونات أندرويد الحديثة (Adaptive + Themed).

## الحصول على ملف APK (بدون تثبيت أي شيء)

1. أنشئ مستودعاً جديداً على GitHub وارفع **محتويات** هذا المجلد كاملةً في جذر المستودع (يجب أن يظهر `settings.gradle` ومجلد `.github` مباشرةً في الصفحة الرئيسية للمستودع، وليس داخل مجلد فرعي). تأكد من رفع المجلد المخفي `.github`.
2. افتح تبويب **Actions** — سيبدأ البناء تلقائياً (يستغرق نحو 3–5 دقائق).
3. بعد النجاح افتح التشغيل ونزّل **sawmill-account-apk** من قسم Artifacts، ثم ثبّت الملف على الهاتف.

لإنشاء إصدار (Release) برابط تنزيل ثابت:

```bash
git tag v1.0.0
git push origin v1.0.0
```

## تحديث البرنامج لاحقاً

استبدل الملف `web/almanchara.html` بنسختك الجديدة ثم ارفعه (`git push`). يعيد GitHub بناء الـ APK تلقائياً.
لتجربة ذلك محلياً: `python3 tools/apply_android_patches.py` (ينسخ الصفحة إلى `app/src/main/assets/index.html` مع التعديلات اللازمة للأندرويد).

لرفع رقم الإصدار عدّل `versionCode` و`versionName` في `app/build.gradle`.

## البناء على الكمبيوتر

افتح المجلد في **Android Studio** ثم Run، أو نفّذ (يلزم JDK 17 وAndroid SDK وGradle 8.5):

```bash
gradle :app:assembleDebug
```

## ما الذي تغيّر عن صفحة الويب؟

| الميزة | في الأندرويد |
|---|---|
| تصدير CSV / Excel / نسخة JSON | تظهر نافذة النظام لاختيار مكان الحفظ (التنزيلات أو Drive…) |
| استعادة نسخة JSON | تعمل عبر منتقي ملفات النظام |
| الطباعة | نافذة طباعة أندرويد (ومنها «حفظ كملف PDF») |
| زر الرجوع | الضغط مرتين للخروج |
| Service Worker / manifest | غير مستخدمين داخل التطبيق |

## ملاحظات مهمة

- **البيانات محلية** داخل التطبيق (localStorage) ولا تُزامَن بين الأجهزة. حذف التطبيق أو مسح بياناته يحذفها، فخذ **نسخة احتياطية** من صفحة الإعدادات بشكل دوري.
- يلزم الإنترنت لتحديث سعر الليرة التركية والمزامنة السحابية وخط Cairo؛ بدونه يعمل التطبيق بخط النظام.
- ملف APK الناتج موقّع بمفتاح التطوير (debug) وهو مناسب للتثبيت المباشر. للنشر على Google Play تحتاج توقيع Release ورفع `targetSdk` حسب متطلبات المتجر.

## هيكل المشروع

```
web/almanchara.html            ← البرنامج الأصلي (عدّله هنا)
app/src/main/assets/index.html ← نسخة الأندرويد (تُولَّد بالسكربت)
app/src/main/java/…/MainActivity.java
app/src/main/res/mipmap-*      ← الأيقونات المولّدة من الشعار
tools/logo.png                 ← الشعار الأصلي
tools/make_icons.py            ← يعيد توليد الأيقونات (python3 tools/make_icons.py)
.github/workflows/build-apk.yml
```
